# Dulno - Webhook

[![CI](https://github.com/taskwolf-net/taskwolf-webhook/actions/workflows/ci.yml/badge.svg)](https://github.com/taskwolf-net/taskwolf-webhook/actions/workflows/ci.yml)

This module provides an interface between Dulno and other external services. Communication takes place via web / http requests. Among other things, the interface can be used to execute workflos.
